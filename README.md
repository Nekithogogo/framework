# RackKeeper — система учета серверного оборудования

Консольное приложение для учета серверов, установленного в них
оборудования, его характеристик и состояния.

## Назначение

RackKeeper помогает вести учет серверов и оборудования: какие комплектующие
стоят в каждом сервере, каковы их характеристики и в каком они состоянии.
Приложение отвечает на повседневные вопросы администратора: есть ли в
сервере свободный слот, можно ли установить в него новый модуль и какое
оборудование неисправно.

## Целевая аудитория

Системные администраторы и инженеры дата-центров и серверных комнат,
а также сотрудники, которые отвечают за закупку и списание оборудования.

## Предметная область

В серверной стоят серверы. У каждого сервера есть расположение (стойка)
и ограниченное число слотов под оборудование. В слоты устанавливается
оборудование: процессоры, модули памяти, диски, сетевые карты. У каждой
единицы оборудования есть характеристики (объем, частота, скорость и т. п.)
и текущее состояние: исправно, неисправно, в ремонте, списано.

Правила предметной области:

- установить в сервер можно только исправное оборудование;
- установка возможна только при наличии свободного слота;
- одна единица оборудования может быть установлена только в один сервер;
- серийный номер оборудования уникален;
- списанное оборудование автоматически снимается с сервера.

## Основные сущности

- **Сервер** — название, расположение, количество слотов;
- **Оборудование** — название, тип, серийный номер, сервер и дата установки;
- **Характеристика** — параметр оборудования: название, значение, единица измерения;
- **Состояние** — исправно, неисправно, в ремонте, списано.

## Возможности

- просмотр серверов с загрузкой (занято/всего слотов, процент, оценка);
- поиск серверов по названию;
- отбор серверов по количеству слотов и сортировка по слотам;
- добавление серверов;
- просмотр, поиск (по названию и серийному номеру) и добавление оборудования;
- добавление характеристик оборудованию;
- проверка возможности установки оборудования в сервер;
- установка оборудования в сервер и снятие с сервера;
- изменение состояния оборудования;
- хранение данных между запусками в JSON-файлах.

## Структура проекта

- `main.py` — точка запуска, меню и пользовательские сценарии;
- `servers.py` — функции работы с серверами;
- `equipment.py` — функции работы с оборудованием, характеристиками и состояниями;
- `storage.py` — загрузка и сохранение данных в JSON;
- `utils.py` — безопасный ввод чисел, строк, дат и вариантов;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты pytest.

Функции из ПР1 (`get_free_slots()`, `get_load_percent()`, `get_load_level()`,
`can_install()`, `get_install_status()`) сохранены и используются
в новых функциях.

## Формат данных

`data/servers.json` — список серверов:

```json
[
    {"id": 1, "name": "srv-db-01", "location": "Стойка A1", "slots": 8}
]
```

`data/equipment.json` — список оборудования. Поле `server_id` равно `null`,
если оборудование не установлено; `state` — код состояния
(`working`, `faulty`, `repair`, `decommissioned`):

```json
[
    {
        "id": 1,
        "name": "Intel Xeon Silver 4314",
        "kind": "CPU",
        "serial_number": "CPU-4314-0001",
        "server_id": 1,
        "installed_at": "2026-09-01",
        "state": "working",
        "characteristics": [
            {"name": "Ядра", "value": "16", "unit": "шт."}
        ]
    }
]
```
