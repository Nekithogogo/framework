# RackKeeper — система учета серверного оборудования

## Назначение

RackKeeper помогает вести учет серверов и установленного в них
оборудования: какие комплектующие стоят в каждом сервере, каковы их
характеристики и в каком они состоянии. Приложение отвечает на
повседневные вопросы администратора: есть ли в сервере свободный слот,
можно ли установить в него новый модуль и какое оборудование неисправно.

## Целевая аудитория

Системные администраторы и инженеры дата-центров и серверных комнат,
а также сотрудники, которые отвечают за закупку и списание оборудования.

## Предметная область

В серверной стоят серверы. У каждого сервера есть расположение (стойка)
и ограниченное число слотов под оборудование. В слоты устанавливается
оборудование: процессоры, модули памяти, диски, сетевые карты. У каждой
единицы оборудования есть характеристики (объем, частота, скорость и т. п.)
и текущее состояние: исправно, неисправно, в ремонте, списано.
Установить в сервер можно только исправное оборудование и только при
наличии свободного слота.

## Основные сущности

- **Сервер** — название, расположение, количество слотов;
- **Оборудование** — название, тип, серийный номер, сервер, в котором оно установлено;
- **Характеристика** — параметр оборудования: название, значение, единица измерения;
- **Состояние** — текущее состояние оборудования (исправно, неисправно, в ремонте, списано).

## Основные функции

- расчет свободных слотов сервера;
- расчет загрузки сервера в процентах и ее оценка;
- проверка возможности установки оборудования в сервер;
- учет серверов и оборудования (добавление, поиск, просмотр);
- установка оборудования в сервер и снятие с него;
- изменение состояния оборудования и учет его характеристик.

На ПР1 реализованы первые четыре функции (кроме учета): `get_free_slots()`,
`get_load_percent()`, `get_load_level()`, `can_install()` и
`get_install_status()`.

## Запуск

```
python main.py
```

## План развития

На следующих этапах планируется:

- консольное приложение с несколькими сценариями и хранением данных в JSON;
- объектная модель предметной области;
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
